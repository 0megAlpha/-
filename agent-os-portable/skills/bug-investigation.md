# Bug investigation skill
1. Capture exact symptoms, time window, environment and a reproducible command or request.
2. Inspect logs, process state, recent diffs, dependency versions and health checks without changing production state.
3. Form competing hypotheses and test the least invasive one first.
4. Preserve original evidence; create a minimal failing test or isolated reproduction.
5. Apply a narrow fix, run regression tests and compare before/after behavior.
6. Document root cause, blast radius, rollback procedure and verification evidence.
