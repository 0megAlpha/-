# SESM / AIxCC Evolution Plane
The existing FuzzingBrain implementation is preserved as the research execution base. SESM adds an explicit discovery tree, capability registry, verification gate, memory boundary and deployment policy.
Security-research capabilities are sandbox/manual unless a local fixture or authorized challenge scope is declared. Migration and economic autonomy are not production features: migration is disabled and economics is simulation-only. Runtime model/LoRA candidates remain offline until evaluated.
Statistical evaluation is evidence, not mathematical proof of superiority.
