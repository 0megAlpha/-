---
title: "Shell Integration (Removed)"
description: "Shell integration is no longer available in Devin CLI."
icon: "square-terminal"
---

Shell integration was a preview feature and was removed in v3000.4.16. It is no longer available.

If you have an existing installation, use `devin shell remove` to clean up leftover managed blocks in your shell configuration. See the [CLI changelog](/cli/changelog/stable) for details.
