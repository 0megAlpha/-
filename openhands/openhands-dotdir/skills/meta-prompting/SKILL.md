# Meta-Prompting
1. Extract objective and constraints.
2. Separate facts from assumptions.
3. Define artifacts and acceptance criteria.
4. Decompose into independently verifiable stages.
5. Assign each stage to the best agent.
6. Define inputs/outputs, failure, retry and rollback rules.
7. Produce an executable workflow.
8. Never expose secrets.
