## Security Considerations

- **Cline auto-approve**：僅在受控環境（VPS 有 fail2ban、tailscale、權限隔離）開啟。
- **MCP 伺服器**：優先選官方或高 star 社區版本，檢查 `mcp.json` 中的 env 變數（避免洩露 token）。
- **Open WebUI plugins**：從可信來源（Classic298/open-webui-plugins）複製，避免未知第三方。
- **Agent Skills**：使用 `npx skills add` 時，檢查 GitHub repo 的 stars、last commit、security scan grade（優先 A 級）。[10][19]
- **VPS 隔離**：建議用 Docker 或 k3s namespace 隔離 agent 運行環境，避免直接訪問主機 file system。

## Deployment Considerations

- **Docker Compose**：將 Cline、OpenCode、OpenHands、Open WebUI 整合到同一 `docker-compose.yml`，共用 redis、postgres。
- **k3s**：若用 k3s，可部署為 StatefulSet（持久化 `~/.openhands`、`~/.cline`、`~/.opencode`）。
- **nginx reverse proxy**：為 Agent Canvas（8000）、Open WebUI（3000）、Cline Webhook（8080）配置 subdomain。
- **監控**：用 v7 router / observability 追蹤 agent token 使用、錯誤率、延遲。
- **備份**：定期備份 `~/.openhands/skills/`、`~/.cline/skills/`、`~/.opencode/skills/` 到 Git repo。

## Optimization Suggestions

1. **Token 效率**：
   - 用 OpenCode 的 `plan` agent 先分析，再調用 `build` agent 執行（減少無謂 token）。
   - Cline 的 `Plan mode` 先確認策略，再切換 `Act mode`。

2. **協作編排**：
   - 用 **OpenHands Automations** 觸發 Cline/OpenCode（GitHub webhook → Agent Canvas → Cline CLI）。
   - 用 **LangGraph** 或 **CrewAI** 編排多 agent（若需要更複雜的狀態圖）。

3. **技能重用**：
   - 將 SKILL.md 放在統一 repo（如 `your-org/agent-skills`），symlink 到各 agent 目錄：
     ```bash
     ln -s ~/agent-skills/.github/skills/mcp-builder ~/.openhands/skills/
     ln -s ~/agent-skills/.github/skills/mcp-builder ~/.cline/skills/
     ln -s ~/agent-skills/.opencode/skills/mcp-builder ~/.opencode/skills/
     ```

4. **離線優先**：
   - 用 Ollama 跑本地模型（Llama 3.1、Qwen 2.5），配置 LiteLLM 作為 router。
   - Open WebUI 啟用 `ENABLE_CODE_INTERPRETER`，本地執行 Python/Node.js。

5. **熱門但非官方**：
   - **Beanie Plugin**（OpenCode）：8 合一功能，高評價 。[9]
   - **Oh-My-OpenCode**：背景 agent、LSP/AST/MCP 工具 。[2]
   - **aivrar/portable-hermes-agent**：Hermes 調度 OpenCode 的 skill（A 級安全掃描）。[10]

***

**總結推薦安裝清單**（直接可執行）：

```bash
# OpenCode
curl -fsSL https://opencode.ai/install | bash

# Cline CLI
npm i -g cline

# OpenHands Agent Canvas
npm install -g @openhands/agent-canvas

# Open WebUI Plugins
docker exec -it open-webui bash -c "
  cd /app/backend/data/plugins &&
  git clone https://github.com/Classic298/open-webui-plugins.git tmp &&
  cp -r tmp/mcp-app-bridge tmp/code-interpreter . &&
  rm -rf tmp
"

# Agent Skills（通用）
npx skills add microsoft/skills --skill mcp-builder
npx skills add anthropic-agent-skills --skill document-skills
npx skills add aivrar/portable-hermes-agent --skill opencode
```

## Security Considerations

- **Cline auto-approve**：僅在受控環境（VPS 有 fail2ban、tailscale、權限隔離）開啟。
- **MCP 伺服器**：優先選官方或高 star 社區版本，檢查 `mcp.json` 中的 env 變數（避免洩露 token）。
- **Open WebUI plugins**：從可信來源（Classic298/open-webui-plugins）複製，避免未知第三方。
- **Agent Skills**：使用 `npx skills add` 時，檢查 GitHub repo 的 stars、last commit、security scan grade（優先 A 級）。[10][19]
- **VPS 隔離**：建議用 Docker 或 k3s namespace 隔離 agent 運行環境，避免直接訪問主機 file system。

## Deployment Considerations

- **Docker Compose**：將 Cline、OpenCode、OpenHands、Open WebUI 整合到同一 `docker-compose.yml`，共用 redis、postgres。
- **k3s**：若用 k3s，可部署為 StatefulSet（持久化 `~/.openhands`、`~/.cline`、`~/.opencode`）。
- **nginx reverse proxy**：為 Agent Canvas（8000）、Open WebUI（3000）、Cline Webhook（8080）配置 subdomain。
- **監控**：用 v7 router / observability 追蹤 agent token 使用、錯誤率、延遲。
- **備份**：定期備份 `~/.openhands/skills/`、`~/.cline/skills/`、`~/.opencode/skills/` 到 Git repo。

## Optimization Suggestions

1. **Token 效率**：
   - 用 OpenCode 的 `plan` agent 先分析，再調用 `build` agent 執行（減少無謂 token）。
   - Cline 的 `Plan mode` 先確認策略，再切換 `Act mode`。

2. **協作編排**：
   - 用 **OpenHands Automations** 觸發 Cline/OpenCode（GitHub webhook → Agent Canvas → Cline CLI）。
   - 用 **LangGraph** 或 **CrewAI** 編排多 agent（若需要更複雜的狀態圖）。

3. **技能重用**：
   - 將 SKILL.md 放在統一 repo（如 `your-org/agent-skills`），symlink 到各 agent 目錄：
     ```bash
     ln -s ~/agent-skills/.github/skills/mcp-builder ~/.openhands/skills/
     ln -s ~/agent-skills/.github/skills/mcp-builder ~/.cline/skills/
     ln -s ~/agent-skills/.opencode/skills/mcp-builder ~/.opencode/skills/
     ```

4. **離線優先**：
   - 用 Ollama 跑本地模型（Llama 3.1、Qwen 2.5），配置 LiteLLM 作為 router。
   - Open WebUI 啟用 `ENABLE_CODE_INTERPRETER`，本地執行 Python/Node.js。

5. **熱門但非官方**：
   - **Beanie Plugin**（OpenCode）：8 合一功能，高評價 。[9]
   - **Oh-My-OpenCode**：背景 agent、LSP/AST/MCP 工具 。[2]
   - **aivrar/portable-hermes-agent**：Hermes 調度 OpenCode 的 skill（A 級安全掃描）。[10]
