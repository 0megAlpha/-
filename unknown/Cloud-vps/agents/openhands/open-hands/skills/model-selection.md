# Multi-Model Selector Skill

## 用途
同一個任務並行調用多個模型，計時 + 質量評分，推薦最佳方案

## 觸發提示詞
"用多模型模式比較這個任務：[任務]"

## 工作流
1. 定義任務目標與評分標準（正確性 / 程式碼品質 / 效率 / 可維護性）
2. 並行調用 5 個模型（例如 glm-5.2、deepseek-r1、qwen3-32b、llama-3.1-8b、claude 等）
3. 記錄每個模型的完成時間
4. 質量評分（每項 1-5 分）
5. 輸出選型報告
6. 推薦最佳方案並說明理由

## 輸出格式
```markdown
| 模型 | 耗時 | 正確性 | 品質 | 效率 | 總分 |
|------|------|--------|------|------|------|

## 推薦
[模型名稱] - [理由]
```
